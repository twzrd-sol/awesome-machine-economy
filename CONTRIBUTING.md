# Contributing to Awesome Machine Economy

Thank you for contributing! This list curates infrastructure, tools, and protocols for the machine economy.

## Guidelines

### What belongs here

- Infrastructure for machine-to-machine commerce (identity, payments, trust, discovery)
- Developer tools and SDKs for building agent economic systems
- Technical standards and specifications
- Research and analysis on the machine economy

### What doesn't belong

- General AI/ML tools (use [awesome-machine-learning](https://github.com/josephmisiti/awesome-machine-learning))
- General cryptocurrency projects (use [awesome-crypto](https://github.com/cmahon/awesome-crypto))
- Projects without documentation or a working release
- Paid services without a free tier or open-source component

### How to add a project

1. Fork this repository
2. Add your project to the appropriate section in **alphabetical order**
3. Use the format: `- [Name](URL) - Brief, factual description.`
4. Keep descriptions under 150 characters
5. Submit a pull request with a clear title

### Quality standards

- Project must have documentation
- Project must be actively maintained (commit within the last 6 months)
- Description must be factual — no marketing language
- One entry per project (don't list in multiple sections)
